# 多智能体协同系统 — 作业全套生成计划

## 场景选择：智慧教室（智能教学协同系统）

---

## 产出清单（共 5 项）

### 1. 完整 Markdown 文档 → 可导出 Word
路径：`产出/多智能体协同系统/作业文档.md`

包含全部 5 个模块：
- 一、应用场景描述（15分）— 智慧教室现状痛点 + AI 协同价值
- 二、智能体团队设计（25分）— 5 个 Agent 的职责、能力、角色表
- 三、协同工作流程（25分）— 文字描述 + 流程图引用
- 四、系统功能设计（20分）— 技术架构 + 功能模块
- 五、深度思考（15分）— 4 道题完整回答

### 2. 协同流程图（baoyu-diagram）
路径：`产出/多智能体协同系统/协同流程图.png`

用 baoyu-diagram 生成：课前→课中→课后→评价 全流程 Agent 交互图

### 3. 系统架构图（baoyu-diagram）
路径：`产出/多智能体协同系统/系统架构图.png`

分层架构图：用户层 → Agent 层 → 数据层 → 基础设施层

### 4. PPT 幻灯片（baoyu-slide-deck）
路径：`产出/多智能体协同系统/演示PPT/`

8-10 页幻灯片，覆盖全部模块，适合 5 分钟演示

### 5. 演示视频脚本
写在文档末尾，含每页 PPT 的口播词 + 时间分配

---

## 执行顺序

1. **先写文档** — 确定全部内容
2. **再生成图** — 基于文档内容生成 2 张图
3. **最后 PPT** — 基于文档+图 生成幻灯片

## 使用的 Skills
- `baoyu-diagram` — 流程图 + 架构图
- `baoyu-slide-deck` — PPT 幻灯片

---

## 验证方式
- 检查 Markdown 文档结构完整（5 模块 + 4 道思考题）
- 检查 2 张图片生成成功
- 检查 PPT 文件导入正常
